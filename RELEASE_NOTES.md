Два готові тестові завдання: статичний Go-файл із фіксованим прапором та динамічна лабораторія з вебом і SSH.

- Незалежні шаблонні прапори вебу та SSH, які платформа генерує для запуску.
- Веб доступний через HTTP-проксі та VPN; SSH — через VPN. Вихід в інтернет через шлюз Laboratory.
- Стандартні архіви імпорту `static.zip`, `dynamic.zip` та спільний `test-exercises.zip`, контрольні суми SHA-256.
- Образ `cybericebox/test-exercises:v1.0.0` для `linux/amd64` та `linux/arm64`; також тег `latest`.

Перевірено валідатором імпорту daemon v2.5.0 та ізольованим мережевим тестом зі справжнім WireGuard, HTTP-проксі й SSH. Розгортання в конкретному заході потребує виділених йому динамічних ресурсів.
